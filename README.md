# G-CLUB

A desktop application for managing a game zone — built as a Object Oriented Programming university project.

## About

G-CLUB helps manage game zone operations, including member records and session tracking, through a simple desktop GUI. It was developed as a team project for the 'Object Oriented Programming 2' course.

## Features

- Member registration and management
- Gaming session & tournament tracking
- Tournament Registration
- Session Booking
- Browsing CO-OP games

## Tech Stack

- **Language:** C#
- **UI:** Windows Forms
- **Database:** SQL Server (via SQL Server Management Studio)

## Getting Started

### Prerequisites

- Visual Studio (2019 or later recommended)
- SQL Server / SQL Server Management Studio
- .NET Framework / .NET

### Installation

1. Clone the repository
   ```
   git clone https://github.com/masumrahmanatul/project_G-CLUB.git
   ```
2. Open the solution file in Visual Studio
3. Set up the database:
   - Open SQL Server Management Studio
   - Run the provided database script
   - Update the connection string in the project's config file to match your local SQL Server instance
4. Build and run the project
